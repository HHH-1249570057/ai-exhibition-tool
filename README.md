# AI 展览工作流工具

一个基于 React + Vite + Tailwind CSS 的前端网页工具。

## 本地运行

```bash
npm install
npm run dev
```

打开浏览器访问：

```text
http://localhost:5173
```

## 打包

```bash
npm run build
```

## 部署

推荐部署到 Vercel / Netlify / Cloudflare Pages。

## 说明

- 项目保存使用浏览器 `localStorage`
- 不需要后端和数据库
- 不同用户/不同浏览器之间项目数据不会同步
